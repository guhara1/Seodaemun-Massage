## 배포 전 필수 작업

모든 페이지의 `canonical`, `robots.txt`, `sitemap.xml`에 임시 도메인 `https://example.com`이 들어 있습니다. 실제 도메인 확정 후 일괄 치환하세요.

```bash
grep -rl "example.com" . --include="*.html" --include="*.xml" --include="*.txt" | xargs sed -i 's|https://example.com|https://실제도메인|g'
```

## SEO 운영 원칙

- 숫자 행정동(홍제1·2·3동, 홍은1·2동, 남가좌1·2동, 북가좌1·2동)은 개별 페이지를 만들지 않고 대표 동 페이지로 통합한다.
- 환승역(충정로역, 신촌역)은 여러 노선에 노출되어도 URL은 하나만 사용한다.
- 지역+역+테마 조합 페이지(예: 신촌역 스웨디시, 홍제역 24시간 홈타이), 출구별 페이지는 만들지 않는다. 해당 키워드는 대표 동·역·테마 페이지 본문에서 자연스럽게만 언급한다.
- 인덱스 대상 페이지 본문은 2,000~2,500자(한글, 공백 포함)를 유지한다. 2,000자 미만 페이지는 `noindex` 처리한다.
- 지역명·역명만 바꾼 복붙 페이지를 만들지 않는다. 페이지마다 FAQ 3~5개를 고유하게 작성한다.
- 푸터에 지역명·역명을 대량 나열하지 않는다.
- 모든 콘텐츠는 건전한 방문 관리 서비스 기준으로 작성하며, 불법·성매매 암시 문구를 금지한다.
